# Public replay versus private reconstruction

The runnable public entry point is `python tools/replay_results.py`. It uses only released categorical/numerical records and the unchanged scoring functions. No source poem, model access or external download is required after installing dependencies.

Full reconstruction and new inference require additional inputs. Do all such work in a **separate private workspace**. The historical files under `provenance/` are evidence records; do not copy them into active freeze locations to imply that newly generated bytes are original frozen artifacts.

## Separately acquired assets

1. Obtain the upstream repository from its authors under terms appropriate to the intended use. The recorded source is [StergiosCha/Greek_Rhyme](https://github.com/StergiosCha/Greek_Rhyme), commit `8ee1773d51133213a87b800ef049ad6e2800f7cd`. Its redistribution license was not established when this release was prepared; public availability is not a license grant.
2. Place a checkout of that commit at `repository_review_2026-09-29/` in the private workspace. Preserve its source bytes/line endings. The required corpus, original benchmark files and verifier code hashes are listed in `provenance/private_assets.json`.
3. Obtain the original 100-pair pilot exclusion file at `evaluation/gold/labels.json` from the study maintainers, subject to source rights. It is required for exact original selection; it is not recoverable from this public release. Using a different exclusion file is a new dataset version, not exact replication.
4. Obtain the author-hosted *Quantifying Greek Rhyme* (2019) PDF through the [publication page](https://ntopintzi.wixsite.com/webpage/copy-of-research). Source URL and PDF/text hashes are in the asset manifest. Place the source PDF at `study_2026-10-08/context/topintzi_etal_2019_author.pdf`. The complete theoretical text is not distributed here.
5. The repaired verifier modules and exact builder are omitted because they transform unlicensed upstream code. Obtain an appropriately authorized version from the maintainers if exact W-condition reconstruction is needed. The engineering procedure and hashes are in [REPAIR.md](REPAIR.md); implementing that procedure independently is not automatically the frozen repaired implementation.

A typical pinned checkout, after arranging access/terms, is:

```bash
git -c core.autocrlf=false clone --no-checkout https://github.com/StergiosCha/Greek_Rhyme repository_review_2026-09-29
git -C repository_review_2026-09-29 checkout 8ee1773d51133213a87b800ef049ad6e2800f7cd
```

The release does not download, execute or publish those assets automatically. Check a private workspace with:

```bash
python tools/check_private_assets.py --workspace PATH_TO_PRIVATE_WORKSPACE
```

It reports only relative asset names and match/missing/mismatch status. Exit 2 means some listed input is missing or differs. A successful check confirms those input hashes, not the presence of all private run evidence or the omitted repair implementation.

## Preparation code

The original dataset selection, validation and freeze scripts are provided unchanged. Once all authorized source inputs exist in a separate workspace with the same relative layout:

```bash
python study_2026-10-08/preparation/prepare_dataset.py
python study_2026-10-08/preparation/validate_dataset.py
python study_2026-10-08/preparation/freeze_dataset.py
```

These commands write new files and refuse an existing data freeze. The internal status string `approved_by_root_awaiting_validation_and_freeze` is an original workflow gate, not evidence of human author approval. Freeze timestamps will differ in a reconstruction. Compare substantive input bytes against the historical data hashes and report discrepancies; do not change a historical hash to make an assertion pass.

The public portable extractor removes the old machine-specific import fallback while preserving extraction logic:

```bash
python -m pip install -e ".[extraction]"
python study_2026-10-08/context/extract_topintzi.py
```

Run it in the private workspace after placing the PDF there. It recovers embedded-font Unicode mappings, then extracts the complete text. It does not OCR raster-only content. Compare the output hash against the recorded text hash; library/environment differences may affect extraction.

`prepare_experiments.py` imports the supplied adapter, which in turn requires the separately acquired original/repaired verifier modules. After those dependencies and prepared data/context are present, its `freeze` action assembles S/C/E prompts and the revision plan. Its `phase2` action uses saved S outputs to construct R/V/W prompts. The public release intentionally contains neither active prompt manifests nor source-bearing prompts.

## New calls and full evidence replay

`study_2026-10-08/runner.py` is the unchanged original runner. It requires authenticated Codex CLI access, a manifest and referenced prompt files. Running it with unfinished jobs issues model calls and consumes account capacity. Public tests mock its subprocess transport and never call models.

After constructing an authorized private experiment, the original command structure is:

```bash
python study_2026-10-08/prepare_experiments.py freeze
python study_2026-10-08/runner.py study_2026-10-08/manifests/phase1.json --output study_2026-10-08/runs/phase1 --workers 6 --max-attempts 2 --timeout 600
python study_2026-10-08/prepare_experiments.py phase2
python study_2026-10-08/runner.py study_2026-10-08/manifests/phase2.json --output study_2026-10-08/runs/phase2 --workers 6 --max-attempts 2 --timeout 600
python study_2026-10-08/analysis.py --no-figures
```

The original recorded CLI was `codex-cli 0.162.0-alpha.2`. Serving aliases/CLI capabilities may differ later. Retain and disclose new runtime metadata; a new call is not expected to reproduce the original model answer byte-for-byte. Never run two runners concurrently against the same output directory. Original freeze/source files, legacy reference layout and complete manifests must be present for the full-evidence scorer.

Replaying the **original private evidence**, including response extraction and transport audits, also requires the authorized original prompt/response/event archive and active frozen artifacts. It cannot be achieved from this public package or merely by acquiring the source corpus. Optional verifier tests are under `tests_private/` and are intentionally outside default public test discovery; they require both verifier versions and their provenance record.
